Embeddable Widget

Giving Tools

Sixteen planned-giving calculators and guides, each one script tag, with nothing a donor types leaving the page.

Educational only, not tax or legal advice.

What it does

A set of self-contained embeds for planned and tax-smart giving: a six-question Giving Navigator that ranks options with reasons, an IRA charitable rollover calculator, a stock gift comparison, a bunching comparison, a state-by-state chart, bequest and beneficiary guides, an estate tax estimator, life-income illustrations, and more. Each tool ends with questions for the donor's own advisor.

Every figure lives in one tax-data file stamped with its tax year and review date, which every tool prints in its footer. A GitHub Action opens a review issue each November and January. Donors can download an advisor summary or pre-filled paperwork as a PDF, built entirely in the browser — no donor data is ever sent anywhere.

What it can do

  • Sixteen tools, each a single <script> tag, plus an all-in-one bundle
  • Advisor-summary PDFs, custodian and broker letters, and pre-filled tax forms built client-side with pdf-lib
  • Shareable scenario links with inputs encoded in the URL
  • North Dakota's 40% endowment credit calculator, switchable off for other states
  • One file for every tax figure, with scheduled review issues
  • Staff tool for IRS-compliant gift acknowledgment letters
  • Keyboard-navigable, 44px targets, works at phone width

Make it your own

Start by forking the repository into your own organization. Everything below assumes you are working in your fork, not this one.

# clone your fork git clone https://github.com/YOUR-ORG/PlannedGiving.git cd PlannedGiving
  1. Fork the repo and edit src/config.js: legal name, EIN, address, contacts, URLs, palette, and shortName. Set features.ndCredit: false outside North Dakota.
  2. Replace the licensed webfonts in fonts/. They are not covered by the MIT license.
  3. Review every figure in src/tax-data.js against current IRS guidance, following docs/TAX-REVIEW.md.
  4. Run node build.js && node gen-pages.js, then node test/run.js to check the math.
  5. Commit dist/, enable Pages from main at the root, and follow docs/FORKING.md for the rest.

Stuck on a step? Open an issue on the repository. Questions from people adapting these for their own institution are the most useful feedback we get.
